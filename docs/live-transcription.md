# 실시간 전사 (BJ 음성 → 문장)

방송 오디오를 계속 받아 BJ가 말한 문장만 뽑는다. 목표는 후보 생성이 **지금 무슨 말이 나왔는지** 아는 것이다.
최종 형태(`src/remote/stt_live.py`)는 지연 중앙값 2~3초, 방송 전체 구간 수신이다.

## 왜 OCI에서 돌리나

집 회선·맥미니에서는 SOOP 오디오가 들어오지 않았다.

| 위치 | 결과 |
| --- | --- |
| 맥미니/집 회선 | 9세션 45초 동안 0.5초 수신 (사실상 0) |
| OCI 동일 코드 | 30초에 712KB 정상 수신 |

그래서 수집·전사·생성은 OCI에서, 승인 콘솔만 tailnet으로 접근하는 구조가 됐다.

## 파이프라인

```
SOOP 라이브 HLS (2초 조각)
  └─ 외부 레코더(soop_native)로 조각 저장
       └─ ffmpeg로 24kHz mono PCM 디코드
            └─ 음량 기반 VAD (RMS 임계, 기본 -38dB)
                 └─ 말하는 구간만 Realtime 전사 세션에 append
                      ├─ 0.7초 침묵 → commit
                      └─ 12초 도달 → commit
                           └─ 문장 완성 → transcript.jsonl {ts, end, text, cost, lag}
```

- 모델: OpenAI Realtime transcription(`gpt-live-transcribe`), `delay=medium`, `languages=["ko"]`.
- VAD는 모델의 턴 감지 대신 직접 한다. `turn_detection=None`으로 두고 우리가 commit 시점을 정한다.
  이유: 노래·효과음이 계속 깔리면 모델 VAD가 계속 열려 있어 문장 경계가 무너진다.
- commit한 구간의 시작·끝·길이를 큐에 쌓아 두고, `committed` 이벤트의 `item_id`에 매핑해
  전사 결과에 정확한 시간 구간과 과금 초를 붙인다.
- 과금은 보낸 오디오 초 × 분당 단가로 `usage.jsonl`에 기록한다. 세션 재연결·실패도 여기에 남는다.

## 이전 방식(파일 전사)과 비교

`src/remote/stt_oci.py`는 20초를 녹음해 파일로 만들어 전사 모델에 보낸다.
조각마다 새로 접속해서 **조각 사이가 비고 결과가 20~45초 늦었다.** 실시간 후보 생성에는 쓸 수 없었다.
지금은 파일 방식은 화면 설명(썸네일) 보조 경로로만 남아 있다.

## 노래 가사 문제

방송은 배경음악을 틀어 두고 말한다. 전사 지침에 "가사는 옮기지 마라"를 넣어도 샜다.
가사가 섞이면 생성기가 가사에 반응한다("나갈 거야" → "나갈 거야?", "찾았다" → "찾았다매").

시도한 방법과 결과:

| 방법 | 내용 | 결과 |
| --- | --- | --- |
| A. 소리로 노래 감지 | 1초 단위 소리 분류(말/노래/음악)로 구간 표시 | 정확도 측정 필요, 미채택 |
| B. 문장 단위 가사 판정 | 전사 한 줄에서 "BJ가 직접 한 말"만 분리, 가사 단어 10분 기억 후 후보 탈락 | 채택. 추가 호출 비용 0(기존 판단 호출에 포함) |
| C. 화자 구분 전사 | BJ 기준 음성을 주고 화자 분리 | 실측상 가사 분리 73%, BJ말 보존 73%, 지연 2.1~2.5초, 분당 $0.003~0.004 |

C는 비용·정확도 모두 매력적이었지만 모델 크레딧 문제로 OpenAI 모델로는 재측정하지 못했고,
Gemini로 대체 측정한 값이다(부류별 15개 표본, 비율마다 ±20%p 오차). 실제 운영은 B로 갔다.

## 실패 모드

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| 전사 0건, 4초마다 재연결 | OpenAI 크레딧 소진(`credit_balance_exhausted`) | 키 교체·충전. 재연결 루프는 조용히 계속되므로 `usage.jsonl`·로그를 봐야 안다 |
| 방송이 끝났는데 계속 과금 | 방송 종료 감지 없음 | 방송 상태 확인 후 세션을 열지 않도록 수정 |
| 같은 서버에서 두 번째 수신 세션 거절 | SOOP이 동시 수신 세션을 막음 | 기존 세션이 받는 조각을 복사해 실험 |
| 전사가 150초 이상 안 옴 | 세션은 살아 있는데 결과 없음 | 상태 카드에 "전사가 멈춘 것 같음" 경고 표시 |

## 비용

- 공식 단가 분당 $0.017 (1시간 $1.02).
- 실측: 6.5시간 방송에서 방송 시간의 95%를 전송, $6.29 → **시간당 $0.97**.
- 배경음악 때문에 VAD가 거의 닫히지 않아 사실상 방송 시간 전체가 과금된다.
- 월 130시간 기준 약 $126/월. 이 비용이 실시간 운영을 끈 직접 이유다.
